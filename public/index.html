DEVELOPER GUIDE

From your first URL to your own app.

01 / REQUEST

Open an endpoint

Use the full address below. The chapter and verse use a dot: 10.15 means chapter 10, verse 15.

/api/v1/verses/10.15

Append ?format=text for a readable text response. Open /read/10.15 for the HTML reader.

02 / DISPLAY

Use the line array

text.lines_ta contains each verse line separately. text.transliteration_ta is a clean single-line string; text.meaning_ta is the Tamil explanation.

In older responses, \n was JSON’s escaped newline. It becomes a line break when parsed. Do not replace escapes inside raw JSON: parse the response first.

Search and filters
Combine chapter, topic, and review. Search with q; URL-encode Tamil query text. Use match=any to match any query word. Pages start at 1; limits range from 1–100.
/api/v1/verses?topic=money&chapter=1&page=1&limit=5
/api/v1/verses?q=சேமி&match=all&limit=5
/api/v1/daily?date=2026-10-08
/api/v1/batch?ids=1.6,10.15

Errors and limits
HTTPWhat to do
400Check parameter names, limits, format, chapter range and calendar date.
401If enabled, send the x-api-key header. Keep private keys on your server.
404The route or verse number is unavailable. Check the chapter index for valid numbers.
405Use GET. This API supports GET, HEAD and OPTIONS.
500Retry later and provide error.request_id to the server owner.
Random selection supports up to 20 unique records. Batch lookup supports up to 50 IDs. Daily selection follows Asia/Kolkata and is stable for the same date, filters and dataset version. Search and topics are deterministic keyword matches.
